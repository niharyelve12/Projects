# 🏡 King County Residential Property Sales Analysis

An interactive **Tableau dashboard project** analyzing residential property sales in **King County, Washington**. This project explores market performance, pricing trends, property characteristics, and location-based insights to help understand what drives home values across the county.

---

## 📌 Project Overview

The goal of this project is to provide a **data-driven view of the King County housing market** by answering questions such as:
- How have residential property sales changed over time?
- Which property types dominate the market?
- How do features like bedrooms, square footage, and building quality affect prices?
- What role do location and environmental factors (e.g., traffic noise) play in home values?

The analysis is presented through **two interactive Tableau dashboards** designed for both high-level insights and detailed exploration.

---

## 📊 Dashboards Included

### 1️⃣ Sales Overview & Market Performance

**Key Metrics:**
- Total Sales Value
- Total Properties Sold
- Average Sale Price
- Average Price per Square Foot

**Visual Insights:**
- Yearly sales trend analysis
- Sales distribution by property type
- Average square footage by property type
- Average sale price by ZIP code

---

### 2️⃣ Property Features & Quality Impact

**Key Metrics:**
- Average Bedrooms
- Average Bathrooms
- Average Living Area (sq. ft.)
- Average Building Grade

**Visual Insights:**
- Sale price trends by year built
- Impact of traffic noise levels on sale price
- Average land value by property type
- Sales by number of bedrooms

---

## 🧰 Tools & Technologies

---

## 🔍 Key Insights

- Single-family homes dominate total sales value.
- 3–4 bedroom homes contribute the highest sales.
- Newer homes command higher prices.
- Traffic noise impacts sale price.
- Location strongly influences pricing.
